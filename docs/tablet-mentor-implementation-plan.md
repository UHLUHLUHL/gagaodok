# 태블릿 멘토 모드 구현 계획

## 범위

휴대폰 버전은 유지하면서, 갤럭시탭에서 가로 분할화면으로 사용하기 좋은 멘토 모드 강화 버전을 구현한다.

이번 범위에는 태블릿 UI, 필기 관리, 사진·PDF·필기 첨부, 드래그 앤 드롭, 그래프 PNG, Obsidian export를 포함한다.

이번 범위에는 Supabase, 로그인, 맥–태블릿 동기화, Realtime, 온라인 파일 저장을 포함하지 않는다. 동기화 설계는 [macOS–Android 학습 데이터 동기화 설계안](mac-android-sync-design.md)에 별도로 기록되어 있다.

## 1. 태블릿 멘토 UI

사용 환경은 가로 방향 좌우 분할화면을 기준으로 한다. 사용자가 앱을 주로 오른쪽 영역에 배치해도 설정·채팅·멘토 기능을 사용할 수 있어야 한다.

항상 접근 가능해야 하는 기능:

- 설정
- 채팅
- 멘토 모드
- 검색
- 첨부
- 필기

현재 태블릿 버전에서 사라진 설정 버튼과 채팅 버튼을 복구한다.

## 2. 채팅 입력창 첨부 메뉴

기존 이미지 전용 버튼을 `+` 버튼으로 변경한다. 메뉴 순서는 다음과 같이 고정한다.

```text
사진
파일
필기
```

### 사진

- 갤러리 이미지 선택
- 기존 이미지 첨부 기능 유지
- 이미지 미리보기와 첨부 취소

### 파일

이번 단계에서는 PDF를 우선 지원한다.

- Android 파일 선택기
- macOS 파일 선택기
- PDF 파일명·용량 표시
- PDF 미리보기
- 지원하지 않는 형식에 대한 안내

### 필기

- 채팅창 위에 떠 있는 필기 패널 표시
- UI에는 “도화지” 대신 “필기” 사용
- 사용자가 `AI에게 전송`을 눌렀을 때만 PNG로 변환해 현재 채팅 첨부에 추가
- 버튼을 누르기 전에는 AI 요청을 보내지 않음

## 3. 필기 기록

새 필기를 열어도 기존 필기는 삭제하지 않는다.

채팅 헤더는 다음 구조를 사용한다.

```text
검색        ⋮
```

세 점 메뉴에는 다음을 넣는다.

- 새 필기
- 필기 기록
- 모델 설정
- 멘토 모드 설정
- 기타 채팅 기능

필기 기록에는 제목, 마지막 수정 시각, 미리보기, 다시 열기, 이름 변경, 삭제, 현재 채팅에 첨부 기능을 제공한다.

필기는 화면 크기와 독립된 좌표계로 저장한다. 전체 화면과 분할화면을 오가도 필기 위치가 변하지 않아야 한다.

## 4. 드래그 앤 드롭

이미지와 PDF를 갤러리, 내 파일, Samsung Notes, 브라우저 등에서 채팅 영역으로 끌어다 놓을 수 있게 한다.

처리 순서:

1. 드래그 이벤트 수신
2. MIME 타입 확인
3. URI에서 파일 정보 읽기
4. 공통 첨부 모델로 변환
5. 채팅 입력창에 첨부 카드 표시

파일 경로가 채팅 텍스트로 입력되면 안 된다. 지원하지 않는 파일은 경로를 입력하지 않고 명확한 오류 안내만 표시한다. 사진 선택, 파일 선택, 드래그 앤 드롭은 하나의 공통 첨부 처리 경로를 사용한다.

## 5. 그래프 PNG

문제에 시각자료가 필요한 경우 구조화된 그래프 명세를 사용한다.

지원 대상:

- 2D 함수 그래프
- 3D 표면 그래프
- 좌표평면 도식
- 점·선분·라벨
- 불연속 함수
- 수치해 곡선

품질 기준:

- 고해상도 PNG
- 축·눈금·격자
- 제목·캡션
- 수식의 LaTeX 렌더링
- 3D 메쉬와 색상 음영
- 불연속 구간 분리
- 렌더링 실패 시 해당 그래프만 제외

그래프의 `f(x)=...` 같은 수식이 일반 텍스트로 노출되지 않도록 수식 렌더러를 보완한다.

## 6. Obsidian export

기존 export 기능은 유지한다. 시각자료가 있을 때는 다음 형식으로 삽입한다.

```markdown
## 시각자료

![[attachments/visual-episode-id-graph-1.png]]

> 그래프 설명
```

규칙:

- 선택된 시각자료만 저장
- 기존 문제 카드와 그래프 PNG는 별도 첨부
- 시각자료가 없으면 기존 Markdown과 동일
- 본문을 수정하면 자동 재생성하지 않고 재검토 상태 표시
- 렌더 실패가 전체 export 실패로 이어지지 않음

## 7. 버전 관리

### 휴대폰 버전

- 기존 applicationId 유지
- 기존 UI와 기능 보존
- 태블릿 전용 UI 미적용

### 태블릿 멘토 버전

- 별도 applicationId 유지
- 멘토 강화 UI 적용
- 가로·분할화면 최적화
- 필기·PDF·그래프 기능 포함

GitHub에서 두 버전을 구분해 빌드하고 배포한다.

## 8. 구현 순서

1. 태블릿 설정·채팅 버튼 복구
2. `+` 첨부 메뉴 구현
3. PDF 첨부 구현
4. 필기 패널과 필기 기록 구현
5. 드래그 앤 드롭 구현
6. 그래프 LaTeX 렌더링 보완
7. Obsidian export 검증
8. 휴대폰·태블릿 버전별 빌드
9. 실제 분할화면과 태블릿 기기 검증
10. GitHub에 버전별 결과 업로드

## 9. 완료 기준

- 태블릿에서 설정과 채팅 버튼이 보임
- 가로 분할화면에서 UI 사용 가능
- 첨부 메뉴가 `사진 → 파일 → 필기` 순서임
- PDF를 첨부할 수 있음
- 이미지·PDF 드래그 앤 드롭 가능
- 파일 경로가 채팅창에 문자로 입력되지 않음
- 기존 필기를 다시 열 수 있음
- 필기 PNG를 AI에 수동 첨부 가능
- 그래프의 LaTeX가 정상적으로 렌더링됨
- Obsidian에 그래프 PNG가 정상 삽입됨
- 휴대폰 버전의 기존 기능이 유지됨
- 동기화 없이도 각 기기에서 모든 로컬 기능이 정상 작동함
