## 작업 시 주의

### 원격 방 이어쓰기

- 원격 방의 새 답장은 해당 방의 허용 writer space에서만 새 turn으로 생성한다. 가져온 turn이나 bubble에는 덧붙이지 않는다.
- 사용자·AI bubble은 연속 order로 보관한다. 충돌 시 아직 원격 projection에 보이지 않은 bubble만 다시 암호화하고, 이미 보이는 사용자 bubble은 유지한다.
- 이 복구 journal과 Gemini cache·호감도는 기기별 로컬 데이터이며 다른 기기에 공유하지 않는다.

- 이 기록은 합의문보다 사용자의 제품 선택을 쉽게 확인하기 위한 별도 기록이다.
- 위 결정만으로 실제 대화의 클라우드 업로드나 양방향 동기화가 승인된 것은 아니다. 합의문에 적힌 단계별 게이트와 안전성 검증은 여전히 필요하다.
- 8번은 검토자 권고(읽기 전용)와 다른 사용자 선택이다. 구현 시 지원하지 않는 방의 대답 방식과 범위를 별도로 명확히 정의해야 한다.
- 2번의 R2 객체는 공개하지 않는다. 계정에 연결된 기기라는 인증을 통과한 경우에만 Worker가 접근을 중계하거나 짧게 유효한 접근 경로를 발급한다.
- 4번의 단톡방·세계선 포함은 canonical schema와 폰 방 백업에 포함한다는 뜻이다. Mac·태블릿에 폰 전용 방을 표시하거나 그 기능을 구현한다는 뜻은 아니다.
- 4·10·11번 조합에 따라 단톡방 AI 응답 한 턴을 지우면 그 턴의 여러 화자 말풍선과 여러 참여자의 기록된 하트 변화가 함께 원자적으로 되돌아간다.
- 12번은 모드를 섞지 않는다: 챗봇은 Android 폰 앱 기준, 멘토는 Mac 기준이다. 말투 로직까지 포함하되 기존 저장 호환성과 profile versioning을 별도 구현에서 검증한다.
- 13번은 기기 간 Gemini cache를 공유하지 않는다는 뜻이다. 각 기기의 로컬 cache는 유지한다.
- 16번의 복구 문구를 잃고 연결된 기기도 모두 잃으면 클라우드 암호문을 복구할 수 없다. 구체적인 키 계층·QR 연결·폐기 절차는 E2EE 계약의 검토가 끝난 뒤 확정한다.
