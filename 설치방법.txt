사피엔스 (카카오톡) 설치 방법
============================

수학 학습용 AI 채팅 앱입니다. macOS 14(Sonoma) 이상이면 돌아갑니다.
인텔 맥, 애플실리콘 맥 둘 다 지원합니다.


1단계. 앱 옮기기
----------------
KakaoSapiens.zip 압축을 풀고, 나온 KakaoSapiens.app 을
응용 프로그램(Applications) 폴더로 끌어다 놓으세요.


2단계. 처음 한 번만: 보안 경고 풀기
-----------------------------------
이 앱은 애플에 등록된 개발자 인증서로 서명되지 않았습니다.
그래서 처음 열 때 "확인되지 않은 개발자" 또는 "손상되었기 때문에 열 수 없습니다"
라는 경고가 뜹니다. 앱이 실제로 손상된 게 아니라, 인터넷으로 받은 파일에
macOS가 붙이는 표시 때문입니다.

터미널(응용 프로그램 > 유틸리티 > 터미널)을 열고 아래 한 줄을 붙여넣으세요.

    xattr -dr com.apple.quarantine /Applications/KakaoSapiens.app

그 다음 앱을 열면 됩니다. 이 작업은 처음 한 번만 하면 됩니다.

※ 위 방법이 막히면:
  시스템 설정 > 개인정보 보호 및 보안 으로 가서
  아래쪽 "KakaoSapiens을(를) 열 수 없습니다" 옆의 [무시하고 열기] 를 누르세요.


3단계. API 키 등록 (필수)
-------------------------
이 앱은 구글의 Gemini AI를 씁니다. 쓰려면 본인 API 키가 필요합니다.
무료로 발급받을 수 있고, 무료 사용량 안에서는 요금이 나오지 않습니다.

  1) https://aistudio.google.com/apikey 접속
  2) 구글 계정으로 로그인
  3) "Create API key" 눌러서 키 생성
  4) 만들어진 키를 복사 (AIza... 또는 AQ... 로 시작합니다)

앱에서:
  채팅방 > 오른쪽 위 메뉴 > 설정 > "Gemini API 키" 칸에 붙여넣고 [키체인에 저장]

키는 이 맥의 키체인에 저장됩니다. 앱 안이나 파일에 남지 않습니다.

※ 처음 저장한 뒤 첫 메시지를 보낼 때
  "KakaoSapiens이(가) 키체인에 접근하려 합니다" 창이 한 번 뜹니다.
  [항상 허용] 을 누르세요.


쓰는 법 간단 안내
-----------------
· 수식은 자동으로 예쁘게 조판됩니다. 문제 사진을 그냥 붙여넣어도 읽습니다.
· 방마다 말투를 따로 줄 수 있습니다.
  프로필 > 말투 에서 캐릭터 이름을 넣고 [찾기] 를 누르면
  그 캐릭터 말투로 설명해줍니다. 저장 전에 [말 시켜보기]로 확인할 수 있습니다.
· 요금은 설정 > 사용량 에서 실시간으로 볼 수 있습니다.


문제가 생기면
-------------
· 수식이 깨져 보인다 → 앱을 완전히 종료했다가 다시 열어보세요.
· "API 키를 먼저 등록해주세요" → 3단계를 다시 확인하세요.
· 앱이 안 열린다 → 2단계의 터미널 명령을 다시 실행해보세요.
